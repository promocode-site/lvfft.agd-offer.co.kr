정가 신상품을 살 때의 순위

아디다스 프로모션코드는 어디에 넣나요?

웰컴 쿠폰은 결제 단계의 프로모션 코드 칸에 직접 입력하고, 생일·레벨업 쿠폰은 같은 결제 단계에서 쿠폰함 목록을 골라 적용합니다. 아울렛 할인은 입력할 것이 없습니다.

쿠폰 발급

  1. adiClub 계정으로 로그인

    웹 또는 adidas 앱에서 로그인한 뒤 계정 메뉴의 쿠폰함(바우처)에 생일·레벨업 쿠폰이 들어와 있는지 먼저 봅니다. 신규 가입자는 환영 이메일에서 개인 프로모션코드를 복사해 둡니다.

    로그인하지 않고 담은 장바구니는 회원 쿠폰을 고를 수 없습니다. 정가 139,000원 상품이라면 생일 쿠폰 15% 기준 20,850원을 놓치는 셈입니다.

  2. 상품 페이지에서 구역 표시 확인

    아울렛 상품인지, '25% 추가 할인' 표시가 있는지, 한정 발매·협업 상품인지 상품 이름과 가격 영역에서 확인한 뒤 사이즈를 골라 장바구니에 담습니다.

    추가 할인 표시 상품은 장바구니에서 가격이 한 번 더 내려갑니다. 판매가 58,000원이면 장바구니에 43,500원으로 찍혀야 정상입니다.

  3. 결제하기로 이동

    장바구니 합계를 확인하고 결제 단계로 넘어갑니다. 배송지 입력 화면과 주문 요약이 함께 나타납니다.

  4. 프로모션 코드 입력 또는 쿠폰 선택

    주문 요약 근처의 프로모션 코드 칸에 이메일로 받은 웰컴 프로모션코드를 붙여 넣고 적용을 누릅니다. 생일·레벨업 쿠폰은 같은 영역에서 보유 쿠폰 목록을 열어 하나를 고릅니다.

    쿠폰이 여러 장이면 할인율이 가장 큰 것을 고르세요. 정가 209,000원 주문에서 레벨 4 생일 쿠폰 20%는 41,800원, 레벨업 쿠폰 15%는 31,350원으로 10,450원 차이가 납니다.

  5. 할인 반영 금액을 보고 결제

    주문 요약에 할인 줄이 생기고 합계가 줄었는지 확인한 뒤 결제수단을 고르고 주문을 확정합니다. 주문 확인 이메일의 결제 금액도 한 번 더 대조합니다.

    결제 후에는 쿠폰을 소급 적용할 수 없습니다. 할인 줄이 보이지 않으면 결제 버튼을 누르기 전에 아디다스 쿠폰이 적용되지 않을 때는 어떻게 하나요?를 확인하세요.

한 주문에 쿠폰을 몇 장까지 쓸 수 있는지는 자주 묻는 질문에서 정리했습니다.
