  1. 앱 설치와 로그인

    APP10을 쓰려면 브라우저가 아닌 네타포르테 앱에서 계정에 로그인합니다. 뉴스레터 할인코드를 받을 계획이면 가입할 때 이메일 수신에 동의합니다.

    웹으로 먼저 주문하면 APP10이 거절될 수 있어, 첫 결제를 앱에서 하는 것만으로 정가 870,000원 기준 87,000원을 지킵니다.

  2. 상품 담기와 상품 표시 확인

    상품 페이지에서 New in this month 표시, 세일 표시, 파인 주얼리 여부를 보고 장바구니에 담습니다.

    신상품 표시가 있는 상품을 빼고 담으면 할인코드 거절 없이 한 번에 결제됩니다.

  3. 결제 단계로 이동

    장바구니에서 결제하기를 누르고 배송지와 배송 방법을 고릅니다. 한국 배송지면 관부가세가 포함된 금액이 표시됩니다.

    리워즈 Gold 회원은 이 단계에서 무료 익스프레스 배송 코드를 쓸 수 있는지 계정의 리워즈 메뉴와 대조합니다.

  4. 프로모션 코드 입력란에 할인코드 입력

    주문 요약 근처의 프로모션 코드 칸에 할인코드를 대문자 그대로 넣고 적용을 누릅니다. 할인 줄이 따로 생기면 반영된 것입니다.

    할인 줄의 금액을 계산과 맞춰 봅니다. 상품가 450,000원에 APAC15면 67,500원이 표시되어야 합니다.

  5. 결제수단 선택과 주문 확정

    결제수단을 고르고 최종 금액을 확인한 뒤 주문을 확정합니다. 확인 메일에 할인 금액이 적혀 있는지 봅니다.

결제 단계에서 할인 줄이 생기지 않으면 네타포르테 할인코드가 안 될 때는에서 원인을 찾으세요.
